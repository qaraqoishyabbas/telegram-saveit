# Timed Photo Saver for Telegram (Saveit)

Этот проект автоматически сохраняет таймерные/самоуничтожающиеся фото и другие медиа из чатов Telegram до их исчезновения. Он использует библиотеку [Telethon](https://docs.telethon.dev/) для работы с Telegram API: скачивает медиа локально и отправляет их в ваши **Избранные сообщения** как оригинальные файлы без сжатия.

## Возможности

* Скачивает таймерные/самоуничтожающиеся медиа из Telegram-чатов.
* Сохраняет скачанные файлы в папку `.downloads/`.
* Отправляет скачанные файлы в **Избранные сообщения** без сжатия.
* Поддерживает документы, фото и видео.
* Скачивает все медиа из одного сгруппированного сообщения/альбома.
* Скачивает медиа, если ваш аккаунт поставил любую реакцию на сообщение.
* Сразу снимает реакцию-триггер перед скачиванием.
* Сохраняет доступные превью закрытых платных медиа в JPG по реакции или команде. Качество миниатюры определяется Telegram; при отсутствии доступного превью выводится сообщение. Покупка за звёзды не выполняется.

## Локальный запуск

Требуется Python 3.9 или новее. Команды выполняются из корня проекта:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -e .
cp .env.example .env
# Укажите API_ID и API_HASH в .env.
python -m saveit
```

После установки также доступна команда `saveit`. Настройки читаются из переменных
окружения и файла `.env` в текущей папке. Зависимости заданы в `pyproject.toml`;
`pip install -r requirements.txt` также устанавливает проект.

## Запуск через Docker для двух аккаунтов

Создайте два файла окружения и укажите в каждом данные соответствующего Telegram-аккаунта:

```bash
cp .env.example .env
cp .env.example .env.account2
```

Соберите образ:

```bash
docker compose build
```

При первом запуске авторизуйте аккаунты по очереди. Оба сервиса используют QR-код: откройте в Telegram соответствующего аккаунта **Настройки → Устройства → Подключить устройство** и отсканируйте код. После успешного входа остановите каждый процесс сочетанием `Ctrl+C`:

```bash
docker compose run --rm saveit-account1
docker compose run --rm saveit-account2
```

Затем запустите оба аккаунта в фоне:

```bash
docker compose up -d
```

Первый аккаунт использует `.env`, сохраняет файлы в `./.downloads/account1` и хранит Telegram-сессию в volume `saveit-account1-session`. Второй использует `.env.account2`, каталог `./.downloads/account2` и volume `saveit-account2-session`.

При необходимости можно запустить только один аккаунт:

```bash
docker compose up saveit-account1
docker compose up saveit-account2
```

Для просмотра логов обоих аккаунтов:

```bash
docker compose logs -f
```

Также один аккаунт можно запустить без Docker Compose:

```bash
docker build -t saveit .
docker run --rm -it --env-file .env \
  -v "$PWD/.downloads:/app/downloads" \
  -v saveit-session:/app/session \
  saveit
```

## Настройка

1. **Клонируйте репозиторий**:

```bash
git clone https://github.com/DevURANIUM/Saveit.git
cd Saveit
```

2. **Создайте файлы `.env` и `.env.account2`**:

```bash
cp .env.example .env
cp .env.example .env.account2
```

3. **Добавьте Telegram API-данные каждого аккаунта в соответствующий файл**:

```env
API_ID=YOUR_API_ID
API_HASH=YOUR_API_HASH
HANDLER=.saveit  # Можно изменить на другую команду
REACTION=*      # Любая ваша реакция; можно указать конкретный эмодзи
```

4. **Запустите оба контейнера**:

```bash
docker compose up --build
```

## Использование

1. **Запустите контейнеры**:

```bash
docker compose up
```

2. **Сохраните медиа**:

* Поставьте любую реакцию на сообщение с медиа.
* Ответьте на любое медиа в Telegram командой `.saveit` или вашей командой из `HANDLER`.
* Если сообщение входит в группу медиа/альбом, будут скачаны все элементы этой группы.
* Медиа будет сохранено в папку `.downloads/account1/` или `.downloads/account2/` и отправлено в **Избранные сообщения** соответствующего аккаунта как оригинальный файл без сжатия.
* Сообщение с командой не удаляется.
* Во время работы скрипт показывает понятный статус: например `Скачиваю 1 файл из сообщения...` или `Скачиваю 3 файла из альбома...`.

### Пример

1. Запустите контейнер:

```bash
docker compose up
```

2. В Telegram поставьте любую реакцию на сообщение с медиа или ответьте командой `.saveit`.

## Обзор кода

* **Настройка клиента**: создает Telegram-клиент с вашими API-данными.
* **Обработчик реакции**: скачивает медиа, если ваш аккаунт поставил любую реакцию при `REACTION=*` или конкретную реакцию из `REACTION`.
* **Обработчик команды**: слушает сообщения с командой `.saveit` или другой командой из `HANDLER`.
* **Обработка медиа**: скачивает медиа и отправляет его в **Избранные сообщения** как оригинальный файл.
